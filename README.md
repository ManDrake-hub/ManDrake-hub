## Geraldino Mandragora

Ph.D. candidate in Industrial Engineering at the University of Naples Federico II.
I work on machine learning, mostly computer vision.

What I have built:

- **Skinner** — the AI behind an explainable screening tool for dermatology and
  trichology that is used by doctors. From a single photo it returns a ranked
  assessment across 23 conditions with severity grading, plus a heatmap of what the
  model weighed. Co-founder and CTO of WholeTech, 2024–2026.
- **Camera-based anomaly detection for public transport** — neural networks running
  in production behind FastAPI, Docker and Kafka.
- **Virtual sensing for vehicles**, the doctoral work. Benchmarked feed-forward,
  recurrent and convolutional-recurrent networks for sideslip estimation; the
  convolutional-recurrent model came close to the best accuracy with roughly 7.5×
  fewer parameters. Built onboard estimators that update a parameter only when the
  measurement passes a consistency, observability and plausibility check.
- **A measurement instrument** — chose the components and wrote the firmware for a
  new generation of the VESevo device for tire viscoelastic properties, then
  integrated it into an autonomous industrial test bench.

Before I trust a model I measure it on the data it will actually meet: an edge-case
test set built on the customer's own material, and conditions held out from training.
Public benchmarks answer a different question.
